# work-packages

Authorised delivery units, one file per Work Package.

**Empty.** No Work Package has been authorised. `BIZTRUST-WP-001`, the skeleton
this repository is, was built under a direct operator instruction recorded in
`badf/authority.yaml`, which is not the expiring implementation grant from a
business authority seat that the P0.2 design requires.

A Work Package lands here when `badf/authority.yaml` records its grant, with an
expiry, and it names its verifier before work starts. See `badf/lifecycle.yaml`
for the transition that needs a human.
